## DV v0.4 · 画质优先

把电脑屏幕实时投到安卓手机上（USB 或 Wi-Fi），主要用来在手机 + VR 盒子里看电脑上播放的 VR 视频。

### 下载
- **DV-PC-v0.4.zip**：电脑端（Windows），已经带好 ffmpeg 和 adb，解压就能用
- **DV-v0.4.apk**：手机端。用 USB 连接时，电脑端会自动给手机安装或更新，一般不用手动装

### 使用
1. 解压 `DV-PC-v0.4.zip`，双击 `DV\DV.bat`（需要 Python 3.8+）
2. **USB**：手机打开 USB 调试，插上线，就会自动打开 DV 并显示画面
   - 电脑识别不到手机时，运行一次 `adb\修复ADB.bat`
3. **Wi-Fi**：手机打开 DV，会自动找到同一网络下的电脑并连接

### 这个版本的变化
- 默认改成**画质优先**：H.265 编码，码率 USB 80 Mbps / Wi-Fi 35 Mbps
- 手机上**双击**画面，切换「完整显示 / 填满屏幕」，用 VR 盒子时选填满
- `DV.bat --mode fast`：延迟优先，适合操作电脑或玩游戏
- `DV.bat --bitrate 120`：手动指定码率（单位 Mbps）
- APK 固定了签名，以后可以直接覆盖升级
